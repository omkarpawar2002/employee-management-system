# Employee Management System

A Django-based web application that allows CRUD operations on employee data. Built with Django and MySQL, this system helps manage employee records efficiently.

## 🚀 Features

- Add new employees
- View detailed employee list
- Update existing records
- Delete employees
- Good interface

## 🖥️ Tech Stack

- Django (Python)
- MySQL
- HTML/CSS/Bootstrap

## ⚙️ How to Run

1. Clone this repo:

```
git clone https://github.com/omkarpawar2002/employee-management-system.git
```

2. Create virtual environment:
```
python -m venv venv
```

3.Activate virtual environment:
```
venv\Scripts\activate
```

4. Install dependencies:
```
pip install -r requirements.txt
```

5. Setup database and run server:

```
python manage.py makemigrations
python manage.py migrate
python manage.py runserver
```
